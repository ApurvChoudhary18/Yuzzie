# @yuzie/git

Git introspection for [Yuzie](https://github.com/ApurvChoudhary18/Yuzzie): remote parsing, branches from a card's title, the commits that belong to a card, code anchors, editor resolution and the post-commit and post-checkout hooks. It runs the `git` you have installed.

You probably want the [`yuzie`](https://www.npmjs.com/package/yuzie) CLI instead. This package
is a building block of it and of [`@yuzie/mcp`](https://www.npmjs.com/package/@yuzie/mcp),
published so they can depend on it.
