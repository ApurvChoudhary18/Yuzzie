# @yuzie/store

The local cache and offline outbox behind the [Yuzie](https://github.com/ApurvChoudhary18/Yuzzie) CLI: Node's built-in SQLite (Node 22.13 and later), with a JSON fallback, so board commands answer instantly and writes made offline wait their turn.

You probably want the [`yuzie`](https://www.npmjs.com/package/yuzie) CLI instead. This package
is one of its building blocks, published so it can depend on it.
