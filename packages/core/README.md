# @yuzie/core

Domain types, zod schemas, the event union and the pure board reducer for [Yuzie](https://github.com/ApurvChoudhary18/Yuzzie): the contract the server, the SDK and the CLI share, so the shape of a card is written down once.

You probably want [`@yuzie/sdk`](https://www.npmjs.com/package/@yuzie/sdk) or the
[`yuzie`](https://www.npmjs.com/package/yuzie) CLI instead. This package is a building block of
both, published so they can depend on it.
