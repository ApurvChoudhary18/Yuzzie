# yuzie

The short name for [`@yuzie/cli`](https://www.npmjs.com/package/@yuzie/cli): a collaborative,
Git-aware project board for the terminal.

```sh
npx yuzie init
```

Everything lives in `@yuzie/cli`; this package only puts `yuzie` (and `yz`) on your PATH. See the
[project README](https://github.com/ApurvChoudhary18/Yuzzie#readme).
