# Keys

`yuzie` with no arguments opens the board. Press `?` there to see these keys.

## Board

| Keys | What they do |
| --- | --- |
| `←` `→` or `h` `l` | Previous / next column |
| `↑` `↓` or `j` `k` | Previous / next card |
| `gg` `G` | First / last card in the column |
| `1`–`9` | Jump to a column |
| `Enter` | Open the card |
| `n` | New card |
| `m` `a` `c` | Move, assign, claim (creates and checks out the branch) |
| `C` | Comment (`Ctrl-D` sends) |
| `e` | Edit the card in `$EDITOR` |
| `w` `d` `D` | Watch, mark done, delete (asks first) |
| `o` | Open the code anchor in your editor |
| `g` | Open the card's branch |
| `/` | Search; `Esc` clears it |
| `f` | Filter (mine, watching, stale, by label or person); `Esc` clears it |
| `A` | Board activity |
| `r` | Refresh |
| `?` | These keys |
| `q` `Ctrl-C` | Quit |

## Card

| Keys | What they do |
| --- | --- |
| `↑` `↓` or `j` `k` | Scroll |
| `Esc` `q` | Back to the board |
| `m` `a` | Move, assign |
| `C` | Comment (`Ctrl-D` sends) |
| `x` | Check off a checklist item (adds one if there are none) |
| `+` | Add a checklist item |
| `e` | Edit in `$EDITOR` |
| `c` `w` `d` `D` | Claim, watch, done, delete |
| `o` `g` | Open the code anchor, open the branch |
| `r` | Refresh |

## In pickers and prompts

| Keys | What they do |
| --- | --- |
| `↑` `↓` or `j` `k` | Choose |
| `Enter` | Confirm |
| `Esc` `q` | Cancel |
